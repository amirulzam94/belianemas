# Belianemas Synergy website mockup

This repository contains the static website mockup for client review.

The site is published from the `main` branch at the repository root: <https://amirulzam94.github.io/belianemas/>.

The contact form is a frontend preview. It validates fields and shows the intended department, but does not send a message. Department routing requires a backend before launch.

Certificates are shown as watermarked previews. Seven certificates open watermarked PDF previews in a new tab, including the complete ISO 9001:2015 and ISO 37001:2025 documents. The other nine open image previews until clean source documents are available. Unwatermarked source PDFs are not included. A static site cannot prevent screenshots or saving a displayed preview.
