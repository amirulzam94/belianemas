# Belianemas Synergy website mockup

This repository contains the static website mockup for client review.

After GitHub Pages is enabled for the `main` branch at the repository root, the preview will be available at <https://amirulzam94.github.io/belianemas/>.

The contact form is a frontend preview. It validates fields and shows the intended department, but does not send a message. Department routing requires a backend before launch.

Certificates are shown as watermarked first-page previews. The public site does not include the source PDFs. A static site cannot prevent screenshots or guarantee that a displayed image cannot be saved.
